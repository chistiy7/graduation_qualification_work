## Дополнения по брифингам (созвоны)

- **Партия образцов S**: набор образцов одного заказа/программы испытаний; в тексте не «множество образцов».
- **Испытательные операции D**: перечень типов испытаний (в коде — `operations`).
- **Матрица состояний**: состояния стенда (свободен / занят / переналадка), допустимость операции, предшествование; не «матрица переходов».
- **Цель работы ≠ целевая функция**: цель — снижение себестоимости испытаний ответственных цилиндрических изделий путём оптимизации планировочного решения испытательной лаборатории; целевая функция — минимизация суммарной себестоимости C (руб., открытая постановка); в тексте цель и целевую функцию не смешивать.
- **Открытая постановка**: min C (руб) без обезразмеривания; ресурсы не лимитированы жёстко.
- **Ячейка 2×2 м**: расчёт L и стоимости размещения — по ячейкам (штучно), не по м².
- **НК исключён** из объёма диплома и режимов программы (твердомер не в номенклатуре по умолчанию).
- **Испытания выполняются над образцами**: термин «изделие/деталь» используется только для описания назначения (вал), но объект испытания в модели — образец.
- **Сопутствующие образцы**: образцы, изготовленные вместе с основными и проходящие те же технологические этапы; применяются для организации контроля партии, не являются «вырезанными из готового изделия».
- **Классификация испытаний (многоуровневая)**: классификация по ортогональным признакам (по виду НДС/нагрузкам; по организации во времени; по определяемым параметрам/свойствам).
- **Перенастройка испытательного стенда**: набор нормируемых действий по подготовке/закреплению/переключениям, влияющий на время и себестоимость.
- **Ячейка сетки лаборатории**: базовая единица дискретизации планировки; размер выбирается по габаритам стендов и зонам обслуживания (ориентировочно 2×2–3×3 м).
- **Запретная зона оборудования / буфер**: область вокруг стенда, где размещение другого оборудования ограничено из‑за вибраций/наводок/опасных факторов.
- **Один образец — одно испытание**: каждому физическому образцу назначается ровно одна маршрутизируемая операция; комбинированный режим — атомарный тип (`tension_torsion` и т.п.), не цепочка простых испытаний на одном образце.
- **T_sum**: суммарная трудоёмкость программы (подготовка + испытания + перенастройки + перемещения), мин.
- **T_cycle**: календарная длительность цикла партии = max занятости стендов, мин.
- **C_area**: стоимость занятости ячеек планировки = N_used × cell_area × rent × (T_cycle/60), руб.
- **C_перем**: труд на перемещение образцов между ячейками = (t_move/60) × c_lab, руб. (в ПО: `CostBreakdown::transport`; устаревшее обозначение C_трансп не использовать в тексте).
- **η**: загрузка стенда η_e = t_busy(e) / T_cycle (не относительно фонда t_fund).

## Параметры модели электроэнергии (добавлено)

- **V — объём рабочей части образца** (м³): входной параметр пользователя; используется в формулах расчёта энергозатрат — механических \(W = \sigma^2 V / (2E)\) и тепловых \(Q = \rho c_p \Delta T \cdot V\).
- **σ_экв(d) — эквивалентное напряжение по Мизесу для операции d** (МПа): паспортный параметр стенда для механических операций; для растяжения/изгиба/сжатия — нормальное напряжение σ; для кручения — √3·τ; для комбинированных — √(σ²+3τ²); используется единообразно в формуле W = σ_экв²·V/(2E); значения — §2.1, таблица А.
- **ΔT — расчётный диапазон температур операции** (°C): паспортный параметр стенда для тепловых операций; определяет тепловую энергию нагрева образца; значения — §2.1, таблица Б.
- **η — КПД стенда** (безразмерный): паспортный параметр; для механических стендов — КПД электромеханического привода; для тепловых — доля электроэнергии, поглощённой образцом; значения — §2.1, таблицы А и Б.
- **ρ, c_p — плотность и удельная теплоёмкость металла**: глобальные константы модели (сталь: ρ = 7850 кг/м³, c_p = 500 Дж/(кг·°C)); используются в тепловой формуле \(Q = \rho c_p \Delta T V\).

## Каталог ПО (lab-test-planner)

- **Вид испытательной операции** (`TestOperationType`): утверждённый перечень из гл. 1–2 (растяжение, кручение, изгиб, усталость, термо, термомеханика, комбинированные и вспомогательные).
- **Режим нагружения** (`WorkloadRegime`): кратковременное, циклическое/длительное, термическое, термомеханическое, комбинированное последовательное/одновременное, вспомогательное.
- **Режим программы лаборатории** (`LabProgramMode`): BasicMechanical, MechanicalExtended, Thermomechanical (`ThermalCycle` — устаревший алиас).
