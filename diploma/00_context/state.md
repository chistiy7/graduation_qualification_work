## Введённые аргументы (не повторять)

- Деталь типа вала — ответственное цилиндрическое изделие; основной образец — цилиндрический; сопутствующие — изготовлены вместе с основными, для контроля партии
- Классификация испытаний: ортогональные признаки (НДС; организация во времени; параметры); без отдельного блока «механические/термические»; **НК исключён**
- Комбинированные испытания; термика — внутри комбинированных программ
- Себестоимость: подготовка, испытание, перенастройка, энергия, труд (вкл. обработку результатов), амортизация; **без отдельной статьи «вспомогательные ресурсы»**
- Лаборатория: номенклатура стендов и зон; «один объект — одна ячейка»; ячейка **2×2 м**, расчёт по ячейкам
- Матрица состояний стендов (свободен/занят/переналадка); запретные зоны и несовместимость соседства
- **Цель работы** — снижение себестоимости испытаний ответственных цилиндрических изделий путём оптимизации планировочного решения лаборатории; **целевая функция** — min C (руб.); цель ≠ целевая функция
