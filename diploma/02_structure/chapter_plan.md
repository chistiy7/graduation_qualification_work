## Глава 3

### Что написать в главе 3

1. Описать входные данные:
   - множество образцов;
   - множество испытаний;
   - множество оборудования;
   - длительности операций;
   - стоимости операций;
   - ограничения последовательности;
   - ограничения размещения.
2. Описать матрицу требований образцов.
3. Описать целевую функцию:
   - частные показатели: суммарное время `T`, себестоимость `C`, перенастройки `N`, длина маршрута `L`, загрузка `η`;
   - обезразмеривание: `T̃ = T/T0`, `C̃ = C/C0`, `Ñ = N/N0`, `L̃ = L/L0`, `η̃ = η/η0`;
   - итоговый критерий как взвешенная сумма нормированных показателей:
     - `K = α1T̃ + α2C̃ + α3Ñ + α4L̃ + α5(2 − η̃)`,
     - `αi ≥ 0`, `Σ αi = 1`;
   - упрощённый критерий допустим при фиксированной планировке: `K′ = α1T̃ + α2C̃ + α3Ñ`.
4. Описать ограничения:
   - совместимость испытания и оборудования;
   - порядок операций;
   - доступность стенда;
   - запрет одновременного выполнения двух операций на одном стенде;
   - запрет размещения оборудования в недоступных зонах.
5. Описать архитектуру программы:
   - препроцессор;
   - расчетное ядро;
   - постпроцессор;
   - графический интерфейс;
   - сохранение и загрузка данных.
